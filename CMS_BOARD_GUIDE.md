# AJOK Website CMS - Board Member Quick Guide

## 🎯 What This Does

Instead of editing your website in GitHub code, you now have a **friendly interface** where you can:
- ✏️ Edit text and descriptions
- 🖼️ Upload and change images
- 📅 Update camp dates and prices
- 🔗 Add links
- 👥 Manage team members

## 🚀 Getting Started

### 1. Access the CMS
Go to: `https://your-website.com/admin/`

### 2. Log In
Click "Login with GitHub" and use your GitHub account

### 3. Start Editing!
Choose what you want to edit from the left menu

## 📝 Common Tasks

### Edit Home Page Text
1. Click **"HomePage - Secties"** in the left menu
2. Choose the section you want to edit (e.g., "Wat is AJOK?")
3. Edit the text in the form
4. Click **"Publish"** at the top to save

### Update Camp Information
1. Click **"Kampen"** in the left menu
2. Click on a specific camp to edit
3. Update dates, prices, description, images
4. Click **"Publish"**

### Add a New Volunteer Function
1. Click **"Vrijwilligerfuncties"** in the left menu
2. Click **"Edit"** on the Kampfuncties file
3. Scroll to the bottom and click **"Add"** to add a new function
4. Fill in the name, description, and upload images
5. Click **"Publish"**

### Change Contact Information
1. Click **"Contactgegevens"** in the left menu
2. Edit email, phone, social media links
3. Click **"Publish"**

### Update Sponsor Information
1. Click **"Sponsors"** in the left menu
2. Add or edit sponsor information and logos
3. Click **"Publish"**

## 💡 Tips

- **Always click Publish**: Your changes only go live when you click "Publish"
- **Markdown formatting**: In text fields with markdown support, you can use:
  - `**bold text**` for bold
  - `*italic text*` for italics
  - `[link text](https://example.com)` for links
- **Images**: You can upload JPG, PNG, WebP images
- **Preview**: Some fields have a preview button to see how it looks

## ⚠️ Important Notes

- Only published changes appear on the website
- Changes take 1-2 minutes to appear after you publish
- All edits are tracked in Git history
- You can undo changes through GitHub if needed

## 🆘 Need Help?

If you can't log in or something doesn't work:
1. Make sure you're at the right URL: `/admin/`
2. Try logging out and back in
3. Clear your browser cache (Ctrl+Shift+Delete)
4. Check that you have access to the GitHub repository
5. Contact the site administrator
